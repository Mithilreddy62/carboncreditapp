# Carbon Credit App 🌱

A comprehensive Flutter-based mobile application designed to revolutionize carbon credit management and environmental sustainability tracking. This app empowers individuals and organizations to actively participate in carbon reduction efforts while earning rewards for their environmental contributions.

## 🌟 Key Features

### 1. Multi-Role System
- **Employee Interface**: Track personal carbon footprint, earn credits, and monitor individual contributions
- **Employer Interface**: Manage company-wide carbon reduction initiatives and employee participation
- **Admin Interface**: Oversee system operations, verify carbon credits, and manage user accounts

### 2. Carbon Credit Management
- Real-time tracking of carbon credits earned
- Monthly and annual carbon reduction goals
- Detailed carbon offset statistics
- Individual and company performance rankings
- Credit trading and transfer capabilities

### 3. Interactive Carbon Map
- Locate nearby carbon credit opportunities
- View verified carbon credit locations:
  - Green Parks
  - Solar Farms
  - Wind Turbines
  - Reforestation Projects
- Real-time location tracking
- Easy credit claiming process
- Distance-based credit calculations

### 4. Activity Tracking
- Log carbon-reducing activities
- Track progress towards sustainability goals
- View activity history and achievements
- Set personal carbon reduction targets
- Receive activity recommendations

### 5. User Profiles
- Comprehensive personal information management
- Detailed activity history
- Carbon credit statistics and achievements
- Environmental impact visualization
- Social sharing capabilities

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>=3.0.0)
- Dart SDK (>=3.0.0)
- Android Studio / Xcode
- Google Maps API Key

### Installation
1. Clone the repository
```bash
git clone https://github.com/yourusername/carbon_credit_app.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Configure environment variables
- Add your Google Maps API key
- Set up Firebase configuration (if using)

4. Run the app
```bash
flutter run
```
